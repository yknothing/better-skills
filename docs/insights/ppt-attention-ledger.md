# PPT 是在做注意力管理吗 —— 专家圆桌裁决与「注意力三账本」框架

> 议题：「PPT 其实是在做注意力管理」
> 形式：5 位独立专家视角并行论证（认知科学 / 叙事结构 / 信息设计 / 红队证伪 / 组织沟通）+ 主持人交叉裁决
> 日期：2026-08-01
> 文档类型：领域洞察（domain insight）。与 `docs/research/` 的仓库分析不同，这里裁决的是一个**领域命题**。

---

## 裁决先行

命题**方向正确，动词错误，作用域缺失**。三句话说完：

1. **动词错误。** 五个视角独立地撞到同一堵墙：注意力不可被"管理"。它在听众脑内，由听众的利害关系、先验知识和任务模板决定。设计者能操作的只有**注意力优先级图上的先验概率**。准确的动词是**投标（bid）**，不是管理。

2. **作用域缺失。** 命题只在**讲者控速（speaker-paced）**的场景下才是主要矛盾。一旦控速权交给读者（留档、异步分发、AI 摘要），稀缺资源立刻从"注意力"变成"检索性"，命题的全部处方随之反号。

3. **它不是同义反复，但需要靠一条定律来支撑。** 红队的指控成立一半：单说"PPT 在管理注意力"确实对一切媒介成立，因而空洞。它的非平凡内容不在描述，而在**显著性预算守恒**这条约束——强调只能通过压低其余项实现，是减法而非加法。这条排除了行业绝大多数默认做法，可证伪，因此非平凡（详见第二节）。

**改写后的命题**：

> PPT 不是在管理注意力，而是**在显著性预算守恒的约束下，为一段口头论证投标注意力的先验分布**。注意力是准入条件，不是目标函数；目标函数在组织账本上——会后能被非作者原样复述的断言数。

## 一、五方论证的收敛与冲突

### 收敛（独立提出、无串通）

| 收敛点 | 提出方 | 强度 |
|--------|--------|------|
| "管理"是错误的动词，设计者只能改先验/投标 | 认知、设计、组织、红队（4/5 明说，叙事以"认知负债"隐含） | 极强 |
| 注意力是必要非充分条件，不是目标函数 | 全部 5 方 | 极强 |
| 信息守恒：删掉的信息只是转移了账户，没有消失 | 设计、组织、红队、叙事 | 强 |
| 控速权归属（讲者 vs 读者）是命题成立与否的分水岭 | 叙事、组织、红队、设计 | 强 |
| 抓住注意力与达成理解/记忆/说服可以负相关 | 认知、叙事、红队 | 强 |

**控速权这条值得单独说。** 四位专家从四个学科各自推出它，而它恰好有元分析级的实证背书：Sundararajan & Adesope 对诱人细节效应的元分析（*Educational Psychology Review*, 2020）把 **learner pacing** 明确列为效应量的调节变量之一。四条独立推理链 + 一条实证链汇到同一个变量，这是本次圆桌置信度最高的结论。

### 冲突与裁决

**冲突 1：Tufte 是反例还是同盟？**

信息设计方裁决：不矛盾。Tufte 在 CAIB 事件中的指控不是"字太多"，恰恰相反——他指控的是**每帧信息分辨率过低、多级项目符号的层级语法替代了因果论证**。而 CAIB 报告 Vol.1 p.191 的原话是："The Board views the endemic use of PowerPoint briefing slides instead of technical papers as an illustration of the problematic methods of technical communication at NASA."

**主持人裁决**：密度作用于**信息**，层级作用于**注意**，两者正交。那张著名的 "Review Of Test Data Indicates Conservatism For Tile Penetration" 幻灯片是注意力投标的**失败案例而非反例**——显著性被分配给了乐观的标题，风险量级（撞击体积 1920 立方英寸 vs 试验样本 3 立方英寸）被排到了层级末端。Tufte 真正证明的是命题的第二半：注意力投标不对信息完整性负责，**因此必须有一个对完整性负责的配套载体**。

**冲突 2：高密度页是负担还是解药？**

流行建议说"一页一点"。但认知方指出：对专家听众，满屏字不是主要错误，**讲者念它才是**（冗余效应的四个前提：逐字冗余 + 同步呈现 + 新手听众 + 讲者控速，缺一不成立；Kalyuga 的专家反转进一步削弱前提三）。信息设计方从另一侧给出同样结论：跨页比较必须在工作记忆里重建，页内并置只需一次扫视，高密度页因此**反而更省**——这正是 small multiples 的全部理由。

**主持人裁决**：**密度不是变量，通道并发才是变量。** 这是本次圆桌对通行建议的最大修正。"每页不超过 6 行"这类阈值找不到一手实证支撑；应当被"讲者语音与屏幕文字的逐字重合率"这一可测量指标替代。

**冲突 3：变化 vs 一致（B5 与数据复盘场景）**

叙事方主张相邻页禁止同景别同构图（否则观众感知为跳切）。但在数据复盘场景，听众的任务是"找异常"，此时固定版式、固定顺序降低查找成本——规则完全反号。

**主持人裁决**：这不是矛盾，是**账本归属不同**。变化服务于会话账本的编码，一致服务于组织账本的检索。规则必须显式声明适用账本与适用域（见第五节规则集）。

**冲突 4：禁止动效 vs 必须制造变化**

信息设计方要求"非数据驱动的动画数 = 0"；认知方要求"仅局部改数的连续页必须制造 transient"（否则变化盲视导致听众用上一页的数值作答——**错误信息入库比未编码更糟**）。

**主持人裁决**：统一为一条原则——**动效只能用于表征数据本身的状态转换**。逐条 build 表征的是"讲述顺序"这一非数据属性，禁止；数值变化的高亮闪烁表征的是数据变化本身，必需。

**冲突 5：空间恒定 vs 禁止跳切**

认知方要求关键数字跨页固定坐标（偏移 ≤2%）；叙事方要求相邻页构图必须变化。

**主持人裁决**：作用对象不同，可共存。变的是**内容区的景别与构图**，不变的是**固定语义槽**（进度指示、恒定指标位）。恒定槽提供跨页寻址能力，变化区提供剪辑点。

## 二、回应红队：这个命题到底禁止了什么

红队的攻击最值得正面回应，因为它是唯一威胁命题存在资格的：任何媒介都在分配注意力，所以该命题是分析真理，和"单身汉未婚"同级；且从它推不出任何具体规范，是奥卡姆意义上的赘余中间项。

**这个攻击对命题的通俗版本完全成立。** 我不为通俗版本辩护。

命题要活下来，必须交出可证伪的内容。它有一条，且只有这一条足够：

**显著性预算守恒定律。** 按 Reynolds & Heeger 的注意力归一化模型，注意增益进入分子、抑制场进入分母——显著性是被除过的**相对量**，全局配额恒定。推论是数学性的而非修辞性的：**"强调"只有一种实现方式，就是压低其余项。**

这条定律排除了下面这些行业默认做法，每一条都可被第三方核查，因此命题非平凡：

- 排除多重强调（加粗+变色+加框+箭头同时用于一个元素）——它把并行的 pop-out 退化为串行的合取搜索，强调等于没强调还多付搜索成本
- 排除"重要的都标出来"——四处高亮在数学上等价于零处高亮
- 排除逐条 build 作为默认动效——它把最强的预注意通道（运动）花在表征"顺序"上
- 排除"再加一页更清楚"——每一页都要从同一个配额里扣

一个能排除这些做法的命题不是同义反复。**但红队的第二项指控我全盘接受**：注意力设计的收益曲线从"糟糕"到"合格"陡峭，从"合格"到"精美"迅速饱和；而利害绑定、汇报人信用、房间政治没有天花板。把一个快速饱和、方差有限的因素命名为"本质"，是**手艺人偏见**。本文档因此不主张 PPT 的本质是注意力管理，只主张：**在讲者控速场景下，幻灯片的边际质量差异主要通过注意力分配机制起作用**。

## 三、统一框架：注意力三账本

五个视角之所以互相冲突，是因为它们在谈**三个不同时间尺度上的三种不同资源**，却共用"注意力"一个词。拆成三本账，冲突自然消解。

| | 账本 A · 瞬时 | 账本 B · 会话 | 账本 C · 组织 |
|---|---|---|---|
| **时间尺度** | ~500 ms | ~60 min | 一周至一个季度 |
| **稀缺资源** | 显著性配额 | 编码带宽 | 承诺槽位 |
| **核心定律** | 归一化守恒（强调 = 减法） | 通道不可并发 | 信息丰富 → 注意力贫乏（Simon 1971） |
| **失败形态** | 显著性与重要性错位 | 读听并发、跳切、悬念不偿还 | 会后无人能复述 |
| **成功指标** | 第一注视点落在最重要断言上 | 关键断言的延迟自由回忆 | 72 小时内非作者的复述次数 |
| **主要学科** | 信息设计、视知觉 | 认知科学、叙事结构 | 组织行为、沟通经济学 |

### 三账本的核心命题：优化目标互相冲突

这才是框架的价值所在，也是它区别于一句口号的地方。

- **动效优化 A，损害 B。** 逐条 build 制造了"有事发生"的错觉（A 上得分），但劫持运动通道去表征非数据属性，并触发注意瞬脱与变化盲视（B 上失分）。
- **精美完整优化 B，损害 C。** 一份逻辑严密、当场无懈可击的 deck，如果没有一句短到能被原样搬走的断言，在 C 上得零分。而决策发生在 C 上——会后的走廊、邮件线程、预算表。
- **完备性优化 C 的责任维度，损害 A 和 B。** 附录是责任分摊设备，删掉等于放弃保险，所以没人真会删。正确解法不是删，是**把它踢出主文件**。

### 由此得到本框架最有操作价值的推论：载体解耦定律

> 信息不会因为被删掉而消失，它只会转移到更贵的账户：讲者口头（不可检索、无版本、无法审计）、听众工作记忆（约 4 个组块，且与读屏争同一通道）、或会后（以追问、返工、错误决策的形式结算）。
>
> 因此：**一份 deck 不能同时服务三个账本。极简幻灯片 + 高密度配套文档 = 合法；极简幻灯片单独存在 = 把设计成本外部化给读者。**

Tufte 的"技术报告替代幻灯片"方案与亚马逊的六页备忘录制度，是同一条定律的两种制度化实现。这也解释了为什么亚马逊的做法**不构成对本命题的反驳**：Bezos 2004 年 6 月 9 日那封主题为 "No powerpoint presentations from now on at steam" 的邮件，废除的不是注意力设计，而是**用一个载体同时服务三本账**这件事。他的理由原话是幻灯片"give permission to gloss over ideas, flatten out any sense of relative importance, and ignore the interconnectedness of ideas"——指控的正是账本 C 的失败。

### 行业默认的优先级是倒置的

| | 从业者实际投入 | 应有优先级 |
|---|---|---|
| 账本 A（配色、对齐、动效） | 最多 | 最低（快速饱和） |
| 账本 B（叙事节律、通道分配） | 中等 | 中 |
| 账本 C（可复述性、载体解耦） | 最少 | 最高（无天花板） |

这个倒置有清晰的机制解释，不是从业者愚蠢：**汇报人当场唯一能获得的反馈信号就是 A 和 B**——有没有人看手机、有没有人点头。C 的信号要几周后才回来，且从不归因给 deck。人向可得的信号优化，这是古德哈特效应的标准形态。

## 四、适用域判据

在应用任何规则之前，先回答三个问题。它们决定命题是否成立、哪本账占主导。

**判据 1（决定性）：控速权在谁手里？**

- 讲者控速、不可回溯 → 命题成立，账本 A/B 主导
- 读者控速、可跳读可搜索 → **命题基本不成立**。剪辑点失去强制性，注意力不再稀缺，第一资源是检索性。此时缺口—填补节律有害，需要的是每页自足、结论前置、标题可扫描

**判据 2：这份材料的产品是什么？**

| 产品 | 主要矛盾 | 本框架适用性 |
|------|---------|-------------|
| 说服 / 争取决策 | 注意力 + 论证 | 完全适用 |
| 留档 / 审批 | 自足性与可检索性 | 反号，勿用 |
| 覆盖度证明（尽调、pitch book） | 完备性与可防御性 | 不适用，留白 = "你没做功课" |
| 合规 / 法务 / 技术规格 | 完整性与法律责任 | 不适用，按注意力删繁是可诉行为 |
| 教学 | 长期留存 | 部分反号（desirable difficulties） |
| 仪式性 / 责任分摊 | 合法性生产 | 不适用，真正被管理的是可追溯性 |

**判据 3：听众是谁？**

任何声称普适的幻灯片规则集，都在隐藏一个未申报的受众假设。三个会翻转规则符号的变量：先验知识（专家反转——冗余文本对专家伤害小得多）、工作记忆容量、母语（非母语听众对屏幕文字的依赖上升，冗余转为有益）。

## 五、规则集

去重、裁决冲突后收敛的 15 条。每条标注所属账本与判定方法。**判定方法必须能被未参与制作的第三方执行**——这是本规则集与常见"PPT 技巧清单"的唯一区别。

### 账本 A · 显著性预算（适用域：全部视觉呈现）

| # | 规则 | 判定方法 |
|---|------|---------|
| A1 | 一页只有一个强调维度 | 页面缩到 12.5% 或高斯模糊后，仍可辨认的元素 ≤1；全 deck 强调色像素占比 <5% |
| A2 | 最显著元素必须是最重要断言 | 第三方只看 3 秒后写下"这页在说什么"，与作者意图比对 |
| A3 | 动效只表征数据的状态转换 | 非数据驱动的动画数 = 0；每页 build 步数 ≤1 |
| A4 | 仅局部改数的连续页必须制造 transient | 帧差分自动检测，每对连续页至少 1 处 |
| A5 | 参考线不该被注视，只该被外周视觉利用 | 参考线对比度低于数据元素 |

### 账本 B · 编码带宽（适用域：讲者控速场景）

| # | 规则 | 判定方法 |
|---|------|---------|
| B1 | **每页声明"读"或"听"，禁止并发** | 录像审计讲者语音与屏幕文字的**逐字重合率**，>30% 判违规。此条替代"每页不超过 6 行" |
| B2 | 一页一个断言，标题是可判真伪的完整句 | 全 deck 名词短语标题数 = 0（Alley 的 assertion–evidence 结构） |
| B3 | 缺口与偿还配平 | 每页标注 O（开口）/ C（闭合）/ S（陈列）/ R（刻意恢复页）；S 占比 >20% 不合格，\|O−C\| >2 不合格 |
| B4 | 翻页后静默约 1 秒再讲关键句 | "页面出现 → 讲者下一个内容词起始"的间隔中位数 <300 ms 判违规 |
| B5 | 禁止跳切 | 同 (景别, 构图轴) 组合连续出现 ≥3 页不合格。**数据复盘场景豁免并反号** |
| B6 | 需要比较的量必须同屏 | 演讲全程"回到刚才那页"次数 = 0 |
| B7 | 固定语义槽跨页坐标恒定 | 同一语义槽的坐标偏移 ≤ 屏幕宽度 2%。与 B5 不冲突：变的是内容区，不变的是槽位 |
| B8 | 高密度页之后一页元素数下降一个数量级，停留 ≥8 秒 | 低于 8 秒会被感知为过场而非停顿 |

### 账本 C · 承诺槽位（适用域：组织决策场景，优先级最高）

| # | 规则 | 判定方法 |
|---|------|---------|
| C1 | 成功指标是 72 小时非作者复述次数 | 会后 72 小时检索邮件/IM/纪要，统计核心断言（词面重合 ≥70%）被**非作者**使用的次数；<1 次即失败，与会议满意度无关 |
| C2 | 不删附录，把它踢出主文件 | 主 deck 页数 ≤ 会议分钟数 ÷ 3，且首页写明"支撑材料见附件 B，本次不宣读"。**附加诊断价值：若有人反对拆分，其反对理由会暴露这份 deck 的真实功能** |
| C3 | AI 摘要门禁 | 作者先密封写下 5 句核心断言；deck 导出纯文本交 LLM 摘要成 5 句；语义命中 <4/5 不得发出。理由：AI 摘要已是第一读者，而它丢弃全部视觉编码——只存在于图表视觉关系中、未被写成句子的结论，在摘要中不存在 |
| C4 | 面对强先验反对者，第 2 页固定为"反对本提案的三条最强理由" | 向反对方核实，≥2/3 确认"是我的真实理由"方为通过；若对方补充了未列出的理由，判定前置对齐失败，会议应推迟 |
| C5 | 坏消息放弃 BLUF，但公布倒计时 | 第 1 页只陈述双方均认可的事实 + "结论见第 3 页"，且不含任何评价性形容词（"严重""可控""良好"） |

### 关于 C5 的机制说明：结论先行何时失效

结论先行（Minto 金字塔 / SCQA / BLUF）在注意力语言下是**危险率为正时的最优停止解**：如果每翻一页都存在正的中止风险（打断、离场、走神、超时），按边际价值降序排列就是最大化期望累计信息价值的策略。这不是修辞偏好，是数学。

它在三种情况下失效，机制各不相同：
- **坏消息**：触发威胁反应，剩余注意力被用于自我防御而非理解
- **需要说服而非告知**：按 ELM，说服要走中心路径，需听众自己完成推理；过早给结论会把听众从"理解模式"切到"评判模式"
- **强先验反对**：偏差同化效应下，同一批证据让对立双方各自更极端

## 六、遗留争议（未达成一致，诚实标注）

1. **注意力优化与学习优化的张力未解决。** Bjork 的 desirable difficulties 表明部分困难提升长期保持；最省注意的幻灯片可能产生最弱的编码，并制造流畅性错觉。本框架的规则集整体偏向"降低摩擦"，这个方向可能在教学场景系统性错误。

2. **红队的反命题未被驳倒**：*优秀的注意力设计与"被有效反驳"负相关*——流畅意味着无摩擦，无摩擦意味着无质疑，而决策质量依赖摩擦。这句话可证伪，原命题不能，因此它在认识论上比原命题更有内容。C4（反对者前置）是对它的部分补偿，但不是完整回应。

3. **归因权重无定量证据。** 注意力设计在一场成功汇报中的贡献占比，本次圆桌没有任何一方能给出可靠估计。多方共识只是它"快速饱和且有天花板"。

4. **跨模态注意瞬脱的效应量待核实。** B4 的 300 ms 阈值基于同模态研究的保守外推，现场跨模态（视觉事件压制随后的听觉词汇编码）证据弱。

5. **B1 的 30% 阈值是工程取值，不是实证阈值。** 冗余效应的方向有强证据，具体切点没有。

## 七、对本仓库的意义

> **Superseding note（2026-08-21）：** 本节保留当时提出独立 `bs-attention-ledger` 的推导，但不再作为当前实施建议。叙事注意力、跨页呼应和 Detail Master 已整合进自研 [`bs-ppt-master`](../../skills/bs-ppt-master/)；外部 `pptx` 继续是独立执行器候选，而不是用户面对的第二套 PPT 工作流。当前不再单独创建 `bs-attention-ledger`。

### 现状缺口

当时 Batch 1 的 PPT 场景只有外部 Reference `pptx`（Anthropic Agent Skills）。它解决的是**执行层候选能力**——如何生成一个 .pptx 文件；它不承担本文三个账本。这不是 `pptx` 的缺陷，是它的正确定位；这一控制层缺口现由 `bs-ppt-master` 承担。

### Skill 提案：`bs-attention-ledger`（提案状态，不实现）

**为什么现在不建：** `CLAUDE.md` 规定 Batch 2/3 冻结，直到每个 Batch 1 skill 通过全部 4 个 gate。本提案遵守该约束，只留设计骨架。

| 项 | 内容 |
|---|------|
| 定位 | Build（`pptx` 覆盖渲染层，注意力层无上游可引用） |
| Tier | standard（中频、中等失败成本） |
| 关键设计 | **入口不是"帮我做 PPT"，而是判据 1–3 的分诊**。判据 1 判为 reader-paced 时，skill 必须拒绝执行并改推文档路径——这是它最重要的行为，也是最容易被实现者省略的 |
| Hard gate 候选 | C2（载体解耦）、C3（AI 摘要门禁）、B1（通道并发禁令）。三条都可自动化核查 |
| 与既有 skill 的关系 | 与 `bs-ui-master` 在账本 A 上有重叠，需划清边界；`pptx` 作为下游渲染执行器 |
| 前置依赖 | Batch 1 全部通过 Gate 4；本文档的规则集需先在 `evaluation/datasets/` 落成测试用例 |

### 可提取的通用模式

以下三条脱离 PPT 场景后仍然成立，是 `docs/patterns/` 的候选条目（尚未提交，需按 `_schema.md` 单独立项）：

1. **预算守恒式约束**（budget-conservation constraint）——把某种"强调/优先级"资源显式建模为总量恒定，从而把加法操作强制转为减法操作。适用于任何存在优先级通胀的设计场景。
2. **控速权分诊**（pacing-control triage）——在执行任何交付物设计前，先判定接收方是否掌握节奏控制权，并据此切换整套规则。
3. **载体解耦**（carrier decoupling）——当一个交付物被要求同时满足互相冲突的目标函数时，正确解法是分裂载体而不是折中。
