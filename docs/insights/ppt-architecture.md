## 裁决先行

1. **目标函数是卓越，抗审是约束。** 写成 `max(实质) s.t. (可辩护, 诚实)`。这个形式不是修辞讲究，它决定了整套方法的结构：锐度与承重的检查在动笔之前，门禁在提交之前，顺序不可交换。
2. **卓越的第一性判据是决策相关的信念位移**：让特定的人，在特定问题上，从相信 A 变成相信 B，且这个位移导致不同的资源投放。它可分解为 **锐度 × 承重效率 × 推进密度 × 决策锚定**，四者任一为零则整体为零。
3. **图表的第一性判据是不可压缩性**：一张卓越的图，其承载的判断无法被一句话无损替代；而它的第一个设计决策是**选比较基准**，不是图形类型。
4. **抗审是必要非充分条件，且与卓越不正交。** 必要，因为建立在未被发现的漏洞上的说服会在漏洞暴露时反向；不充分，因为"无可攻击的断言集为空"可以靠不说有内容的话廉价达成。不正交的方向是有益的：完备标注会让不存在的模式消失，所以它是**伪洞察的检测器**。

## 一、一次方向纠正：把约束当成目标函数

这一节记录的是本文档第一版的错误，因为它比任何论证都更能说明目标函数为什么重要。

**第一版把目标函数设成了"经得起对抗性评审"。** 产出的东西全是防守指标：论证闭合性、无悬空断言、措辞不超出证据等级、失效条件显式化、让步数非零。这些指标本身没错，错在**位置**——它们是可行域，不是被最大化的量。skill 也因此叫 `bs-defensible-deck`，一个描述防守属性的名字。

**退化解论证。** 以"不可被推翻"为目标函数，存在一个平庸的全局最优：**同义反复**。"我们应持续关注市场变化并动态调整策略"绝对抗审、绝对无价值。任何按"漏洞数为零"打分的方法论都会被优化器推向这句话。这个病理可以先验推出，不需要实证——而它恰好解释了第一版的产物为什么读起来严密但没有力量。

**两位新专家独立给出了同一诊断**，措辞几乎一致：

> 架构专家："错误不在于指标错，而在于把约束当成了目标函数。约束'不可被推翻'存在一个平庸的全局最优解：同义反复。"
> 图表专家："错误不是内容错，是把约束集当成了目标函数。目标函数应写作 `max 洞察密度 s.t. 完备标注与非操纵约束`。防守清单是 s.t.，不是 max。"

两条独立推理链落到同一个形式化，这是本轮置信度最高的结论。

**纠正带来的结构性后果**，全都不是措辞层面的：

| 维度 | 第一版（抗审为目标） | 现版（卓越为目标） |
|---|---|---|
| 入口 | 先写台账、预注册阈值 | 先写**信念差表**：谁、现在信什么、离场时信什么、什么证据、之后做什么不同的事 |
| 主张 | 只要求措辞不超出证据 | 必须过**锐度五检验**（取反测试、换名测试、代价具名、可反对性、决策差异） |
| 架构 | 论证依赖图（防漏洞） | **三根承重支柱**（删掉即崩塌）+ 推进密度 + 决策锚定，依赖图降为审计工具 |
| 图表 | 自证要素清单（防攻击） | **比较基准先行**（compared to what）+ 不可压缩性，自证要素降为底线 |
| reference 结构 | 全篇审计标准 | 每个文件反转为 **Part 1 卓越 / Part 2 底线** |
| 校验器 | 20 项，全部服务约束 | 22 项，其中信念差、比较基准、锐度留痕**服务目标函数** |
| 命名 | `bs-defensible-deck`（防守属性） | `bs-ppt-architecture`（工作物：PPT 的架构） |

命名本身走过三次，三次都说明同一条规则：**用工作物命名，不用评价属性命名。**

1. `bs-defensible-deck`：`defensible` 描述「扛得住」，是约束的属性。
2. `bs-deck-substance`：`substance` 描述「有内容」，是目标的属性。和上一版同类，只是把防守词换成了质量词。`deck` 还把用户的领域词 PPT 换成了咨询英语。
3. `bs-ppt-architecture`：领域是 PPT，工作物是架构（论证结构 + 配图配表）。仓库自研 skill 一律 `bs-` 前缀、全词不缩写，所以不是 `ppt-arch`。抗审仍然只是实质的一个副产品，不进入名字。

还有一条被纠正的具体规则：门禁失败时**不允许**通过把主张对冲成无人反对的说法来销号。那正是用约束换目标，现在它被显式写成 Rule 1 的违规项。

## 二、目标侧：卓越的正向标准

第一轮请的四位专家全是审计视角，所以第二轮补了两位负责"什么是卓越"。以下是他们的产物中最有操作价值的部分。

### 架构：四个乘数因子

**卓越 = 锐度 × 承重效率 × 推进密度 × 决策锚定**，任一为零则整体为零。

**锐度**：平庸主张与锐利主张的差别不是语气，是结构——平庸主张"真、但无人会反对"，锐利主张"真、且有具名的输家"。五个检验里最锋利的是**取反测试**：把主张整句取反，若取反后仍像一句正常的建议（"加大投入" ↔ "停止投入"），原句有信息量；若取反后荒谬到没人会说（"我们应忽视客户"），原句是废话。配套的还有换名测试（把公司名换成竞争对手是否仍成立）、代价具名（必须点名放弃什么、谁的预算被削）、可反对性（能否指名一位会在会上公开反对的人）。

必须强调一个区分，否则这套标准会被误用：**锐度不是超出证据说狠话**。它是"在证据允许的上限处把话说到位"。对冲到无人反对，和超出证据显得决断，是方向相反的两种失败。

**承重效率**：为什么是三根支柱而不是八根，有三条独立机制——Cowan（2001）把短期记忆容量修正为约 4±1 个组块，这是听众离场后能自主复述的硬上限；听众默认把并列支柱读作合取，k 根支柱的可信度约 p^k，而反驳者只需击破一根；以及**二传手带宽**——你的听众要向他的上级复述，k>4 时压缩必然发生，且由别人完成，你丧失了对主张的控制权。三根的真正好处是**你替听众做了压缩**。

选支柱用**承重实验**：假设该论点被完全推翻——结论崩塌则是支柱，结论仍成立但明显变弱则是加固（进附属页），毫发无伤则是装饰（进附录）。若删掉任意一根结论都不倒，这不是支柱结构而是**证据堆**。再加独立性检查：若一个前提被否证会同时打掉两根，那两根实为一根。

**推进密度**三个可外包的判别：标题词性统计（名词短语标题占比 >20% 即失败）、**标题串联测试**（抽出全部标题连读，必须构成自足论证——出现断点即缺页，语义重复即冗余，读起来像目录即无架构）、删除测试（删掉此页结论是否仍同样成立）。

**决策锚定**：首页列 1–3 个决定，含决策者、选项、截止日、**不决定的代价**；每页标注服务哪个编号。抽 5 页问"服务哪个编号、删了那个决定会不会变"，任一失败即移附录。理论依据是 Howard 的信息价值定义：**不改变任何选项排序的信息，其价值精确为零**。

### 图表：不可压缩性与比较基准

**第一性判据是不可压缩性**：读者在卓越图表上完成的动作是**发现**，不是确认。判定用盲测三人法——遮住标题，三人各看 30 秒写下看到的独立事实，取交集记为 I。I ≥ 2 配整页；I = 1 且需重复监测配一格；I = 1 且一次性则**删图写句子**；I = 0 图失败。

例外必须写明，否则会误杀：监测型读数（控制图、仪表盘）的价值来自位置恒定与重复读取，I=1 合法；**否证型**图表在读者先验错误时，"确认一句话"本身就是巨大增益——Rosling 的收入-寿命散点几乎每张都在否证一个流行错觉。

**第一个设计决策是选比较基准，不是图形类型。** 任何管理断言都可写成"X 相对 Y 在 Z 上差 D"，Y 缺失则 D 不存在，图就只是数值展览。基准按**归因干净度**排序：反事实（对照组、DiD、合成对照）> 模型残差与内部分层 > 同类横比 > 目标 > 自身历史 > 竞品，但决策相关性可以覆盖排序——要批预算的人可能更需要目标基准而不是对照组。

其中最有价值的一条是**对抗性基准测试**：把基准换成"对我最不利但仍然合理"的那个，若结论方向翻转，则必须两个基准同图并置，或把结论降级为"在 A 口径下"。这一步把防守从事后答辩**前移成了设计约束**——它同时服务目标和约束，是两者耦合最紧的地方。

配套还有一条硬规则：**任何需要读者做减法的图都未完成**。差值要被直接编码——以基准为 0 线画 Δ、索引化、或并置到共同标尺。

**洞察密度 ≠ 数据密度**：前者的分子是独立可行动的差（即 I），后者的分子只是数字个数。十万点散点云是高数据密度、低洞察密度；两个处理组加对照加置信带只有六个数，但结论不可压缩。

**small multiples 是最强单件武器**，三条机制：把序列比较改成并置比较（绕开工作记忆容量）、恒定框架隔离信号（只有被比较的变量在跨面板变化）、以及感知升级（共享标尺把判断从角度/面积降到共同标尺上的位置，即 Cleveland-McGill 精度阶梯的最高层）。它同时提升诚实性——共享标尺让"只放赢的那个面板"不可能，全枚举让 cherry-picking 显式化：**缺面板是可见的空洞，不是沉默**。这就是它被放在"卓越"而非"底线"一侧的原因。

**表格的卓越**来自 Bertin 的洞见：**排序是分析动作，不是排版动作**。按结论所在列降序并声明排序键；差异列强制存在（任何读者需要心算的比较都必须预计算）；判定用 60 秒测试——不懂业务的人能否说出最大、最小、哪一行反常。

### 由此得到的一条修复顺序

这是本轮最有实操价值的推论：**如果一份材料极其抗审但很平庸，问题不在证据层，而在主张层与决策锚定层**。因此修复顺序必须是 **先重写主张 → 再重排支柱 → 最后回填证据**。反向操作（先补证据）只会把平庸夯得更实，这是最常见的返工浪费。

对应的工程含义就是 skill 的 workflow 排序：锐度、承重、推进的检查是动笔前的第一道，抗审门禁是提交前的最后一道。**顺序颠倒即是第一版的真正错误。**

## 三、约束侧：四方论证的收敛

四位专家互不可见、并行论证。收敛点如下（括号内为独立提出方）：

| 收敛点 | 提出方 | 强度 |
|---|---|---|
| 假防御比不防御更可疑：加一页风险、加一句局限、±10% 敏感性分析，在评审者眼里等同于示弱 | 攻击方、流程方、架构方 | 极强 |
| 真防御的形式是"翻转点 + 当前安全距离"，不是"影响 × 概率"矩阵 | 攻击方、架构方 | 强 |
| 因果措辞必须由证据等级授权，"驱动 / 带来 / 助力"是偷渡因果而不承担举证责任 | 架构方、攻击方 | 强 |
| 图表的合法性不能依赖口头补充；需要讲者解释的图已经输掉了这一轮 | 图表方、攻击方 | 强 |
| 载体必须分裂：现场帧 / 留档文档 / 数据包，三层各自承担不同的举证责任 | 图表方、架构方、流程方 | 强 |
| 自我批评必然失假，除非有先于结果的承诺 + 独立举证方 + 不可回填的痕迹 | 流程方、架构方 | 强 |
| 让步数为 0 是缺陷信号而非质量信号 | 流程方（唯一提出，但主持人判定为最强的单条规则） | — |

### 冲突与裁决

**冲突 1：完备性 vs 可读性。** 图表方要求每张图自带 9 类自证要素，同时承认"过度自证本身会被解读为心虚"。

裁决：这不是同一层面的冲突，用**载体分裂**解决。现场帧只保留**不可下沉的最小自证集**（断言标题、n、时间窗、一行口径、零基线、不确定性），因为这六项对应最高频攻击；完整要素、剔除账、敏感性缩略图下沉到留档文档，每张现场帧标注其留档页码。这个动作的真正价值是**把"我口头解释"转换成"可核查的引用"**。

**冲突 2：显式架构 vs 说服效果。** 架构方指出 rebuttal 在不对称审查环境下会被武器化——评审方只需否决、无需承担机会成本时，你的失效条件清单就是现成弹药。

裁决：承认这是结构性的，写不好听的话也消不掉。可行折中是 rebuttal 与翻转点保留在可索引的附录，口头层主动提出并**配上回应**。这里有一个方向明确的实证依据：O'Keefe 关于单面 / 双面信息的元分析（*Communication Yearbook* 22, 1999）区分了**带反驳**与**不带反驳**的双面信息，前者优于单面，后者劣于单面。操作结论很硬：**裸承认"我们也考虑了 X 的风险"比不提 X 更糟。**

**冲突 3：分布优先 vs 汇总即决策对象。** 图表方主张分布几乎总优于均值，理由不是 Anscombe 那类"形状可以千差万别"，而是更窄的一条：**对抗性提问几乎都落在尾部**——谁在亏、谁超时、p99、最差的那批客户。均值恰好是抹掉尾部的统计量。

裁决：接受，但保留四类例外（量的语义就是总和、全量普查、n 极小时直接列全部原始值、隐私敏感）。

**冲突 4：动效与变化。** 未在本轮出现，但与上一轮的裁决一致：动效只能表征数据本身的状态转换。

## 四、约束侧的度量：可辩护性 = 主动交出的攻击面比例

四位专家给的目标函数其实是同一个函数在四个层面的投影：

| 层面 | 该层的目标函数 |
|---|---|
| 攻击面 | 材料主动暴露最弱处的程度 |
| 论证 | 闭合性 + 承重可见性 + 措辞与证据等级匹配 |
| 证据 | 排除竞争性解释 |
| 过程 | 让步数非零 |

统一表述：

> **可辩护性 = 作者主动交出并量化了影响的攻击面 ÷ 全部存在的攻击面**

这个比率是可估计的，因为分母有目录：`references/attack-catalog.md` 收录了六类共三十余条攻击手法。分子是材料中自曝且带量化影响的条目数。这把一句价值判断（"要诚实"）变成了一个可清点的量。

它也解释了为什么"假防御"会**降低**得分而不是不影响得分：一页只列宏观、竞争、监管风险的风险页，看起来增加了分子，实际上它占用了自曝的位置却没有交出任何真实攻击面——评审者据此推断作者知道该做什么、却选择了做样子。**假防御是分子上的负项。**

## 五、三个问题的额度

攻击方给出的最有价值的单项产物：董事会评审者通常只有三个问题的额度。按"答案不可预演 + 无论怎么答都改变后验"筛选，最优的三个是——

1. **"什么都不做，这条曲线会是什么样？"** 一次检验基线、因果、价值三件事。答不上来，后面所有数字自动降级为轶事。
2. **"什么结果出现，你会承认这件事做错了？"** 区分"想清楚了"与"想赢"。给不出阈值意味着结论不可证伪，也意味着事后无法追责。
3. **"有没有你看过、但没放进这份材料的数字？"** 唯一无法提前排练的问题。它检验的是人不是材料，而人的诚实度决定前两个答案值多少。

顺序是承重的：(1) 定性质，(2) 定边界，(3) 定可信度。

这三问被直接编码为 skill 的三条硬门禁：G2（禁止句必须含数字阈值 + 日期 + 具名数据源）、G7（反证检索留痕）、以及 Phase 4 的正文自曝规则（最弱项与不利证据必须在正文而非附录）。

## 六、核心设计决策：把门禁下降到可机器校验的台账

四位专家都要求"判定方法必须能被第三方执行"，但都默认由**人**去执行。这里有一个实现层面的硬问题他们没有面对：

**deck 本身几乎不可机器校验。** pptx 是一个视觉容器，标题是不是完整陈述句、因果动词有没有越权、翻转点是不是真做了敏感性分析——这些在二进制文件里没有可靠的解析入口。于是所有"可自动化"的判定在落地时都退化成人工抽查，而人工抽查一忙就跳过。这是绝大多数评审清单最终变成合规仪式的机制。

解法是把**可审计性下降到一个结构化中间产物**：`claims.md`（论证台账）。台账用固定格式承载 C/E/A/W/R 编号图、证据等级、翻转点、signpost、禁止句、概率与结算三元组。台账可以被程序完整解析，因此门禁作用于台账而不是页面。

这个决策有三个连带收益，其中第二个是决定性的：

1. **门禁真的硬——但硬度是被攻击出来的，不是设计出来的。** `scripts/check-claim-ledger.js` 做 22 项结构检查，任一失败退出码为 1。四个夹具全部入库为回归夹具，因为"门禁真的会 fail"是核心主张，必须可复现：合规 L2 与合规 L0 退出 0，格式违规与**形式合规但实质空洞**各自退出 1。最后那一类是 Gate 2 对抗评审打出来的，见第九节。
2. **台账先于页面，等价于预注册。** 这是约束侧裁决与目标侧"信念差先于一切"的交汇点：台账里的因果动词、阈值、翻转点必须在看到"哪些数据好看"之前钉死。如果允许先做页面后补台账，那么动词和阈值就是结果的函数——正是 Scheel 等人测到的那 96% 的生成机制。**顺序本身就是机制**，所以它是 Phase 1 的 HARD-GATE（从属于 Rule 2），不是一条建议。
3. **它给出了一个可传递的交付物。** 台账在会议结束后依然存在，且可被下一轮评审、事后复盘、结算日核对直接使用。

诚实标注：脚本只校验**形式**。warrant 可以写成同义反复，翻转点可以填一个没做过敏感性分析的数字。**自动化检查只能证伪形式缺陷，永远不能证明论证质量。** 它的真正价值是把人类对抗性注意力从格式纠察中释放出来，去攻 warrant。缺了那个人，这套东西退化成合规仪式——这一点写在 skill 的 `references/architecture.md` 末尾，不藏在脚注里。

## 七、与「注意力三账本」的真实冲突

上一轮圆桌留下一条**未被驳倒**的红队反命题：

> 优秀的注意力设计与"被有效反驳"负相关——流畅意味着无摩擦，无摩擦意味着无质疑，而决策质量依赖摩擦。

本次的 skill 站在那条反命题一侧——但位置要说准：它**最大化的是实质**（锐利主张、承重结构、揭示性图表），**约束**是可辩护与诚实。约束要求摩擦，所以它与注意力优化冲突；冲突的是可行域，不是被最大化的量。两轮产物不能假装兼容：

| 维度 | 注意力账本主张 | 实质层（约束：可辩护） | 冲突性质 |
|---|---|---|---|
| 信息密度 | 显著性预算守恒，强调靠减法 | n、口径、剔除说明、不确定性是"证据墨水"，不可删 | 真冲突，作用于同一块屏幕面积 |
| 页内元素 | 一页一断言，元素越少越好 | 需要比较的量必须同屏，跨页比较要在工作记忆里重建 | 表面冲突，实为账本归属不同 |
| 叙事 | 缺口—偿还节律维持注意力 | 结论前置便于抽查，悬念妨碍检索 | 真冲突，由控速权决定谁优先 |
| 附录 | 未被引用的附录是噪音 | 附录是举证与责任分摊装置，不可删只可外置 | 无冲突，两轮结论一致 |

**解法是同一条定律：载体解耦。** 上一轮从"信息守恒"推出它，本轮从"完备性 vs 可读性"推出它。两条独立的推理链落到同一个结论，这是本项目目前置信度最高的设计原则：**当一个交付物被要求同时满足互相冲突的目标函数时，正确解法是分裂载体，不是折中。**

因此 `bs-ppt-architecture` 的 Phase 0 第一个问题就是控速权归属——它决定这份材料归哪本账管。判为 reader-paced 时，skill 必须拒绝按现场演讲的规则施工。这是它最重要的行为，也是最容易被实现者省略的一条。

## 九、Gate 2 对抗评审的结果：这套方法对它自己生效

skill 写完后按仓库的 Gate 2 走了一轮同行评审：两个**独立上下文**的 agent，一个正方一个红队，红队只拿到交付物、拿不到我的推理过程——这正是 skill 自己 Phase 5 HARD-GATE 规定的做法。结果值得完整记录，因为它是这套方法有效性的唯一直接证据。注意：这一轮评审的对象是目标函数尚未纠正的第一版（当时名为 `bs-defensible-deck`）；发现全部落在约束机械上，目标侧能力当时基本缺席。

**18 项发现，17 项接受并改，1 项部分接受，0 项拒绝。** 完整处置见 [`docs/reviews/bs-ppt-architecture/2026-08-18-gate2-response.md`](../reviews/bs-ppt-architecture/2026-08-18-gate2-response.md)。

三项最有价值的发现：

**1. 红队击败了校验器。** 它构造了一份格式完美、实质空洞的台账，拿到 16/16 全过、零警告。手法包括：用 ISO 日期本身充当"数字阈值"（正则里 `2027-01-01` 提供了数字）、`via internal review` 满足"具名数据源"、`almost certain, 1-5 percent`（band 与区间从未交叉验证）、`counterfactual: 不适用，没有对照组`（用否认满足必填）、`signpost: vibes | 1 | daily | tbd | tbd | tbd`（六段齐全但内容是占位符）、以及一个小写的 `### c3` 标题——它对所有检查不可见，却对任何人类读者都读作一条 claim。更狠的是它证明**空着 `## Assumptions` 节比写得差得分更高**，因为空节让翻转点检查 vacuous pass。

修法不是"把漏洞补上就完了"，而是**把那份空壳台账永久留作回归夹具**（`assets/claims.exploit-probe.md`），并写一个 18 条断言的回归套件锁死每一个已关闭的漏洞。要防御的命题从"校验器不可被击败"改成了**"它被击败的方式都已记录并被断言覆盖"**——前者是无法兑现的承诺，后者可以。

**2. 红队发现 skill 在定义 Rule 3 的文件里违反了 Rule 3。** 我在 `review-protocol.md` 里写了："两个文献群的差别不是研究者品格，是承诺时点。"这是从一个**非随机分配的跨语料库观察性比较**得出的独占因果归因——按我自己写的 T0–T5 阶梯，那是 T2 证据，只许说"变化期间发生了"，不许说"就是因为它"。

这个错误穿过了起草和自查，被一个只读交付物的独立上下文抓住。修正后的措辞是"作者提出的最可信解释"，而且**这段纠正被留在原地而不是抹掉**——它是"检查对作者本人生效"的最干净的一次演示，比任何论证都有说服力。它同时证明了为什么同上下文自查不能替代独立攻击：产生错误的推理链无法审计自己。

**3. 正方发现三处 pattern 来源归属错误。** `verification-rules` 是 Vercel 不是 Superpowers，`named-anti-patterns` 是 Taste Skill 不是 Superpowers，`format-significance-gates` 是 Anthropic 不是 CE。核对 `docs/patterns/README.md` 后确认三处全错，已修。这类错误无法靠"更认真一点"避免，只能靠核对。

其余修改中影响面较大的：分级规则原先只定义了 2×2 中的一个象限（现补全）；"硬门禁是二值且不可协商"这个说法被**撤回**（判定二值、后果由用户承担，可执行的规则只有"失败不得被软化或伪装成通过"）；定性提案原先会被数字阈值门禁逼出假精度——而假精度正是本 skill 攻击面目录里列出的破绽，这是"比没有 skill 更糟"的真实情形（现由 `evidence-basis` 字段处理）。

**元层面的一句话**：让步数 = 4（撤回了两个声明、下调了一个检查的主张、缩小了校验器的书面适用范围）。按 skill 自己的 Phase 5，让步为 0 会被报为门禁失败；它不是 0。

## 十、已知局限

1. **攻击者是 LLM，不是真实的利益相反方。** Nemeth 等人的研究表明"指派的魔鬼代言人"主要产生对原立场的认知加固，效果劣于真实异见。我们用"独立上下文 + 外部完成条件"绕行——不要求真实信念，用可判定的成功标准替代。这是工程绕行，**不是等价替代**，L3 因此要求外部裁判。第七节的实测结果说明这个绕行至少是有效的（红队确实击败了校验器，而不是夸奖它），但单次成功不构成对 Nemeth 结论的反驳。
2. **形式检查永远不能证明质量。** 这是第七节的直接教训，且不可关闭：warrant 可以是同义反复，翻转点可以是没人推导过的数字，`grade: T5` 可以是自封的。具体漏洞已堵并被断言锁定，但类别本身堵不住。已写入 skill 的 `## Known Limits` 与校验器输出的每一次页脚。
3. **门禁可被 Goodhart 化。** 凑八条无痛异议、做一次装饰性让步，就能满足字面要求。对策是抽查销号证据的质量而非计数，但这一条目前没有自动化手段。
4. **收益曲线形状未知。** 上一轮红队指出注意力设计的收益快速饱和。可辩护性是否同样饱和，本次没有证据。我的推断是不同——它作用于最弱环节，而最弱环节的改进是非线性的（一处致命缺陷即可否决全案）。**标注为推断，未验证。**
5. **Gate 4 尚未跑通。** 本 skill 的三条测试提示已写入 `evaluation/datasets/batch-1-test-prompts.json`，但基线对比（有 skill vs 无 skill）未执行。README 的场景覆盖表中不得声称其"优于基线"。
6. **台账格式是本项目自定义的。** 它不是任何行业标准，因此不具备跨组织的可迁移性。若要与外部评审流程对接，需要额外的映射工作。
