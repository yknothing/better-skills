# 经得起对抗性评审的 deck —— 专家圆桌裁决与 `bs-defensible-deck` 的设计依据

> 议题：如何设计一份 PPT Skill，重点不在美观，而在论证架构与配图配表能扛住高强度对抗性评审
> 形式：4 位独立专家视角并行论证（对抗性评审方 / 论证结构 / 信息设计与定量报告 / 审前自检机制）+ 主持人交叉裁决
> 日期：2026-08-18
> 落地物：[`skills/bs-defensible-deck/`](../../skills/bs-defensible-deck/)
> 前置：[`ppt-attention-ledger.md`](./ppt-attention-ledger.md) —— 本文与之存在真实的目标冲突，见第五节

---

## 裁决先行

1. **目标函数不是"被理解"，而是"排除竞争性解释"。** 被理解只是准入条件——一份读不懂的材料连被排除的资格都没有。这个替换改变了几乎所有设计决策：不再删繁就简，而是优先呈现最可能被用来反驳自己的那批数据。
2. **可辩护性的唯一度量是自曝比例。** 四位专家从四个方向撞到同一句话：材料的强度等于它主动暴露自身最弱处的程度。凡是需要评审者用问题挖出来的，一律按"故意隐藏"计价。
3. **唯一有实证支撑的干预是改变承诺时点。** 不是让作者更诚实，而是让主张在看到数据之前落盘。Scheel、Schijen 与 Lakens（*AMPPS*, 2021）的对照最有力：常规心理学文献中 96% 的论文报告首个假设获得支持，而结果未知时即完成同行评审的注册报告只有 44%。两个文献群的差别不是研究者品格，是承诺时点。
4. **门禁必须落在可机器校验的产物上，而 deck 本身几乎不可校验。** 这是本次实现的核心设计决策，也是这个 skill 与"又一份检查清单"的根本区别，见第四节。

## 一、四方论证的收敛

四位专家互不可见、并行论证。收敛点如下（括号内为独立提出方）：

| 收敛点 | 提出方 | 强度 |
|---|---|---|
| 假防御比不防御更可疑：加一页风险、加一句局限、±10% 敏感性分析，在评审者眼里等同于示弱 | 攻击方、流程方、架构方 | 极强 |
| 真防御的形式是"翻转点 + 当前安全距离"，不是"影响 × 概率"矩阵 | 攻击方、架构方 | 强 |
| 因果措辞必须由证据等级授权，"驱动 / 带来 / 助力"是偷渡因果而不承担举证责任 | 架构方、攻击方 | 强 |
| 图表的合法性不能依赖口头补充；需要讲者解释的图已经输掉了这一轮 | 图表方、攻击方 | 强 |
| 载体必须分裂：现场帧 / 留档文档 / 数据包，三层各自承担不同的举证责任 | 图表方、架构方、流程方 | 强 |
| 自我批评必然失假，除非有先于结果的承诺 + 独立举证方 + 不可回填的痕迹 | 流程方、架构方 | 强 |
| 让步数为 0 是缺陷信号而非质量信号 | 流程方（唯一提出，但主持人判定为最强的单条规则） | — |

### 冲突与裁决

**冲突 1：完备性 vs 可读性。** 图表方要求每张图自带 9 类自证要素，同时承认"过度自证本身会被解读为心虚"。

裁决：这不是同一层面的冲突，用**载体分裂**解决。现场帧只保留**不可下沉的最小自证集**（断言标题、n、时间窗、一行口径、零基线、不确定性），因为这六项对应最高频攻击；完整要素、剔除账、敏感性缩略图下沉到留档文档，每张现场帧标注其留档页码。这个动作的真正价值是**把"我口头解释"转换成"可核查的引用"**。

**冲突 2：显式架构 vs 说服效果。** 架构方指出 rebuttal 在不对称审查环境下会被武器化——评审方只需否决、无需承担机会成本时，你的失效条件清单就是现成弹药。

裁决：承认这是结构性的，写不好听的话也消不掉。可行折中是 rebuttal 与翻转点保留在可索引的附录，口头层主动提出并**配上回应**。这里有一个方向明确的实证依据：O'Keefe 关于单面 / 双面信息的元分析（*Communication Yearbook* 22, 1999）区分了**带反驳**与**不带反驳**的双面信息，前者优于单面，后者劣于单面。操作结论很硬：**裸承认"我们也考虑了 X 的风险"比不提 X 更糟。**

**冲突 3：分布优先 vs 汇总即决策对象。** 图表方主张分布几乎总优于均值，理由不是 Anscombe 那类"形状可以千差万别"，而是更窄的一条：**对抗性提问几乎都落在尾部**——谁在亏、谁超时、p99、最差的那批客户。均值恰好是抹掉尾部的统计量。

裁决：接受，但保留四类例外（量的语义就是总和、全量普查、n 极小时直接列全部原始值、隐私敏感）。

**冲突 4：动效与变化。** 未在本轮出现，但与上一轮的裁决一致：动效只能表征数据本身的状态转换。

## 二、主持人综合：可辩护性 = 主动交出的攻击面比例

四位专家给的目标函数其实是同一个函数在四个层面的投影：

| 层面 | 该层的目标函数 |
|---|---|
| 攻击面 | 材料主动暴露最弱处的程度 |
| 论证 | 闭合性 + 承重可见性 + 措辞与证据等级匹配 |
| 证据 | 排除竞争性解释 |
| 过程 | 让步数非零 |

统一表述：

> **可辩护性 = 作者主动交出并量化了影响的攻击面 ÷ 全部存在的攻击面**

这个比率是可估计的，因为分母有目录：`references/attack-catalog.md` 收录了六类共三十余条攻击手法。分子是材料中自曝且带量化影响的条目数。这把一句价值判断（"要诚实"）变成了一个可清点的量。

它也解释了为什么"假防御"会**降低**得分而不是不影响得分：一页只列宏观、竞争、监管风险的风险页，看起来增加了分子，实际上它占用了自曝的位置却没有交出任何真实攻击面——评审者据此推断作者知道该做什么、却选择了做样子。**假防御是分子上的负项。**

## 三、三个问题的额度

攻击方给出的最有价值的单项产物：董事会评审者通常只有三个问题的额度。按"答案不可预演 + 无论怎么答都改变后验"筛选，最优的三个是——

1. **"什么都不做，这条曲线会是什么样？"** 一次检验基线、因果、价值三件事。答不上来，后面所有数字自动降级为轶事。
2. **"什么结果出现，你会承认这件事做错了？"** 区分"想清楚了"与"想赢"。给不出阈值意味着结论不可证伪，也意味着事后无法追责。
3. **"有没有你看过、但没放进这份材料的数字？"** 唯一无法提前排练的问题。它检验的是人不是材料，而人的诚实度决定前两个答案值多少。

顺序是承重的：(1) 定性质，(2) 定边界，(3) 定可信度。

这三问被直接编码为 skill 的三条硬门禁：G2（禁止句必须含数字阈值 + 日期 + 具名数据源）、G7（反证检索留痕）、以及 Hard Rule 2（最弱项必须在正文而非附录）。

## 四、核心设计决策：把门禁下降到可机器校验的台账

四位专家都要求"判定方法必须能被第三方执行"，但都默认由**人**去执行。这里有一个实现层面的硬问题他们没有面对：

**deck 本身几乎不可机器校验。** pptx 是一个视觉容器，标题是不是完整陈述句、因果动词有没有越权、翻转点是不是真做了敏感性分析——这些在二进制文件里没有可靠的解析入口。于是所有"可自动化"的判定在落地时都退化成人工抽查，而人工抽查一忙就跳过。这是绝大多数评审清单最终变成合规仪式的机制。

解法是把**可审计性下降到一个结构化中间产物**：`claims.md`（论证台账）。台账用固定格式承载 C/E/A/W/R 编号图、证据等级、翻转点、signpost、禁止句、概率与结算三元组。台账可以被程序完整解析，因此门禁作用于台账而不是页面。

这个决策有三个连带收益，其中第二个是决定性的：

1. **门禁真的硬——但硬度是被攻击出来的，不是设计出来的。** `scripts/check-claim-ledger.js` 做 20 项结构检查，任一失败退出码为 1。四个夹具全部入库为回归夹具，因为"门禁真的会 fail"是核心主张，必须可复现：合规 L2 与合规 L0 退出 0，格式违规与**形式合规但实质空洞**各自退出 1。最后那一类是 Gate 2 对抗评审打出来的，见第八节。
2. **台账先于页面，等价于预注册。** 这是第 4 条裁决与第 3 条的交汇点：台账里的因果动词、阈值、翻转点必须在看到"哪些数据好看"之前钉死。如果允许先做页面后补台账，那么动词和阈值就是结果的函数——正是 Scheel 等人测到的那 96% 的生成机制。**顺序本身就是全部机制**，所以它是 Hard Rule 1 而不是一条建议。
3. **它给出了一个可传递的交付物。** 台账在会议结束后依然存在，且可被下一轮评审、事后复盘、结算日核对直接使用。

诚实标注：脚本只校验**形式**。warrant 可以写成同义反复，翻转点可以填一个没做过敏感性分析的数字。**自动化检查只能证伪形式缺陷，永远不能证明论证质量。** 它的真正价值是把人类对抗性注意力从格式纠察中释放出来，去攻 warrant。缺了那个人，这套东西退化成合规仪式——这一点写在 skill 的 `references/argument-architecture.md` 末尾，不藏在脚注里。

## 五、与「注意力三账本」的真实冲突

上一轮圆桌留下一条**未被驳倒**的红队反命题：

> 优秀的注意力设计与"被有效反驳"负相关——流畅意味着无摩擦，无摩擦意味着无质疑，而决策质量依赖摩擦。

本次的 skill 正是站在那条反命题一侧：它优化的是**被有效反驳的能力**。所以两轮的产物之间存在真实的目标冲突，不能假装兼容：

| 维度 | 注意力账本主张 | 可辩护性主张 | 冲突性质 |
|---|---|---|---|
| 信息密度 | 显著性预算守恒，强调靠减法 | n、口径、剔除说明、不确定性是"证据墨水"，不可删 | 真冲突，作用于同一块屏幕面积 |
| 页内元素 | 一页一断言，元素越少越好 | 需要比较的量必须同屏，跨页比较要在工作记忆里重建 | 表面冲突，实为账本归属不同 |
| 叙事 | 缺口—偿还节律维持注意力 | 结论前置便于抽查，悬念妨碍检索 | 真冲突，由控速权决定谁优先 |
| 附录 | 未被引用的附录是噪音 | 附录是举证与责任分摊装置，不可删只可外置 | 无冲突，两轮结论一致 |

**解法是同一条定律：载体解耦。** 上一轮从"信息守恒"推出它，本轮从"完备性 vs 可读性"推出它。两条独立的推理链落到同一个结论，这是本项目目前置信度最高的设计原则：**当一个交付物被要求同时满足互相冲突的目标函数时，正确解法是分裂载体，不是折中。**

因此 `bs-defensible-deck` 的 Phase 0 第一个问题就是控速权归属——它决定这份材料归哪本账管。判为 reader-paced 时，skill 必须拒绝按现场演讲的规则施工。这是它最重要的行为，也是最容易被实现者省略的一条。

## 七、Gate 2 对抗评审的结果：这套方法对它自己生效

skill 写完后按仓库的 Gate 2 走了一轮同行评审：两个**独立上下文**的 agent，一个正方一个红队，红队只拿到交付物、拿不到我的推理过程——这正是 skill 自己 Rule 6 规定的做法。结果值得完整记录，因为它是这套方法有效性的唯一直接证据。

**18 项发现，17 项接受并改，1 项部分接受，0 项拒绝。** 完整处置见 [`docs/reviews/bs-defensible-deck/2026-08-18-gate2-response.md`](../reviews/bs-defensible-deck/2026-08-18-gate2-response.md)。

三项最有价值的发现：

**1. 红队击败了校验器。** 它构造了一份格式完美、实质空洞的台账，拿到 16/16 全过、零警告。手法包括：用 ISO 日期本身充当"数字阈值"（正则里 `2027-01-01` 提供了数字）、`via internal review` 满足"具名数据源"、`almost certain, 1-5 percent`（band 与区间从未交叉验证）、`counterfactual: 不适用，没有对照组`（用否认满足必填）、`signpost: vibes | 1 | daily | tbd | tbd | tbd`（六段齐全但内容是占位符）、以及一个小写的 `### c3` 标题——它对所有检查不可见，却对任何人类读者都读作一条 claim。更狠的是它证明**空着 `## Assumptions` 节比写得差得分更高**，因为空节让翻转点检查 vacuous pass。

修法不是"把漏洞补上就完了"，而是**把那份空壳台账永久留作回归夹具**（`assets/claims.exploit-probe.md`），并写一个 15 条断言的回归套件锁死每一个已关闭的漏洞。要防御的命题从"校验器不可被击败"改成了**"它被击败的方式都已记录并被断言覆盖"**——前者是无法兑现的承诺，后者可以。

**2. 红队发现 skill 在定义 Rule 3 的文件里违反了 Rule 3。** 我在 `review-protocol.md` 里写了："两个文献群的差别不是研究者品格，是承诺时点。"这是从一个**非随机分配的跨语料库观察性比较**得出的独占因果归因——按我自己写的 T0–T5 阶梯，那是 T2 证据，只许说"变化期间发生了"，不许说"就是因为它"。

这个错误穿过了起草和自查，被一个只读交付物的独立上下文抓住。修正后的措辞是"作者提出的最可信解释"，而且**这段纠正被留在原地而不是抹掉**——它是"检查对作者本人生效"的最干净的一次演示，比任何论证都有说服力。它同时证明了为什么同上下文自查不能替代独立攻击：产生错误的推理链无法审计自己。

**3. 正方发现三处 pattern 来源归属错误。** `verification-rules` 是 Vercel 不是 Superpowers，`named-anti-patterns` 是 Taste Skill 不是 Superpowers，`format-significance-gates` 是 Anthropic 不是 CE。核对 `docs/patterns/README.md` 后确认三处全错，已修。这类错误无法靠"更认真一点"避免，只能靠核对。

其余修改中影响面较大的：分级规则原先只定义了 2×2 中的一个象限（现补全）；"硬门禁是二值且不可协商"这个说法被**撤回**（判定二值、后果由用户承担，可执行的规则只有"失败不得被软化或伪装成通过"）；定性提案原先会被数字阈值门禁逼出假精度——而假精度正是本 skill 攻击面目录里列出的破绽，这是"比没有 skill 更糟"的真实情形（现由 `evidence-basis` 字段处理）。

**元层面的一句话**：让步数 = 4（撤回了两个声明、下调了一个检查的主张、缩小了校验器的书面适用范围）。按 skill 自己的 Rule 7，让步为 0 会被报为门禁失败；它不是 0。

## 八、已知局限

1. **攻击者是 LLM，不是真实的利益相反方。** Nemeth 等人的研究表明"指派的魔鬼代言人"主要产生对原立场的认知加固，效果劣于真实异见。我们用"独立上下文 + 外部完成条件"绕行——不要求真实信念，用可判定的成功标准替代。这是工程绕行，**不是等价替代**，L3 因此要求外部裁判。第七节的实测结果说明这个绕行至少是有效的（红队确实击败了校验器，而不是夸奖它），但单次成功不构成对 Nemeth 结论的反驳。
2. **形式检查永远不能证明质量。** 这是第七节的直接教训，且不可关闭：warrant 可以是同义反复，翻转点可以是没人推导过的数字，`grade: T5` 可以是自封的。具体漏洞已堵并被断言锁定，但类别本身堵不住。已写入 skill 的 `## Known Limits` 与校验器输出的每一次页脚。
3. **门禁可被 Goodhart 化。** 凑八条无痛异议、做一次装饰性让步，就能满足字面要求。对策是抽查销号证据的质量而非计数，但这一条目前没有自动化手段。
